ECOTRACK

ECOTRACK est un projet de gestion intelligente des déchets par IoT. Les capteurs mesurent le remplissage et l'environnement des poubelles, optimisant ainsi les tournées des camions et réduisant l'empreinte carbone.

Technologies utilisées

  • Raspberry Pi
  • Capteurs ultrasoniques, humidité, température
  • PHP / Node.js serveur
  • Interface Web HTML/CSS
