UNO Online

UNO Online est un jeu multijoueur développé avec ReactJS et Java Spring Boot. Il permet de jouer au célèbre jeu de cartes en réseau, avec synchronisation en temps réel via WebSocket.

Technologies utilisées

  • ReactJS pour le front-end
  • Spring Boot pour le back-end
  • WebSocket pour la communication temps réel
  • Docker pour le déploiement
